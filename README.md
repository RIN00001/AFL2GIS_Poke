# FieldDex

Offline GIS collection game for Universitas Ciputra–Hokky. Python handles spatial analysis; Three.js renders the game.

- **Game:** `FieldDex.exe`
- **Game map:** `data/manual_scene.json`
- **Saved progress:** `outputs/manual_game_save.json`
- **Asset sources and licenses:** [CREDITS.md](CREDITS.md)

`backend`, `frontend` and `config` contain the game; `tests` checks its behavior; `scripts` contains setup and launcher source/build files. `.venv` is the installed Python environment.
